# MindMap Studio - Visual Learning Platform

A React-based interactive mind map application for studying and exam preparation.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- React Flow (@xyflow/react)

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

Deploy to any static hosting service like Vercel, Netlify, or GitHub Pages.
